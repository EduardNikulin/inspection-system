# Система автоматизации обработки обращений граждан в инспекцию труда

Программный комплекс представляет собой серверное консольное приложение на языке программирования Python, предназначенное для автоматизации процессов регистрации, распределения, обработки и архивного хранения жалоб граждан, а также для обеспечения внутренней коммуникации между участниками системы.

## Стек технологий и зависимости
- Язык программирования: Python 3.10+
- Система управления базами данных: Microsoft SQL Server
- Протокол взаимодействия с СУБД: T-SQL / ODBC Driver 18 for SQL Server
- Ключевые библиотеки: pyodbc, hashlib, tkinter



## Архитектура системы и разграничение прав доступа
Доступ к функционалу системы разграничен на основе ролевой модели (Role-Based Access Control):
1. Гражданин: подача официальных обращений с возможностью прикрепить сопутствующие документы, редактирование заявлений в статусе "Новая", просмотр архивных документов, ведение двусторонней переписки с назначенным инспектором.
2. Работник (Инспектор труда): аудит закрепленных за сотрудником обращений, изменение статусов делопроизводства, ведение переписки с заявителем по конкретному инциденту.
3. Администратор: полный аудит базы данных обращений, назначение ответственных исполнителей, безвозвратное удаление записей, администрирование учетных записей персонала (CRUD-операции).

## Технические особенности реализации
- Обеспечение информационной безопасности: хранение аутентификационных данных пользователей реализовано в защищенном виде с применением криптографического хэширования по алгоритму SHA-256.
- Оптимизация работы с СУБД: реляционные выборки и транзакции спроектированы на уровне чистого SQL с использованием множественных соединений таблиц (JOIN), агрегатных функций и вложенных подзапросов, что минимизирует нагрузку на сервер БД.
- Изоляция конфигурации: параметры подключения к СУБД вынесены на уровень переменных окружения (Environment Variables), что исключает компрометацию инфраструктурных данных в исходном коде.

## Развертывание и запуск проекта

1. Клонируйте репозиторий с исходным кодом:
   ```bash
   git clone https://github.com/EduardNikulin/inspection-system.git
   cd inspection-system
   ```

2. Убедитесь в наличии установленного в системе системного драйвера ODBC Driver 18 for SQL Server.

3. Создайте локальную базу данных со следующим системным наименованием:
   ```text
   Никулин_ТрудИнспекция
   ```

4. Установите необходимые программные зависимости:
   ```bash
   pip install -r requirements.txt
   ```

5. При необходимости переопределения параметров подключения задайте системные переменные окружения `DB_SERVER` и `DB_NAME`.

6. Осуществите запуск главного модуля приложения:
   ```bash
   python main.py
   ```
   
   *!!!Примечание для Unix-систем: для корректной работы модуля файлового менеджмента на базе tkinter в операционных системах семейства Linux требуется предварительная установка системного пакета python3-tk.!!!*
